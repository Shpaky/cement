# Правила проекта

## Текущее состояние
Репозиторий ещё не инициализирован: нет package.json, исходников и .git.
Первый шаг — скаффолдинг Astro-проекта. При этом в package.json обязаны
появиться скрипты `build`, `lint` и `test:a11y`, на которые опирается
процесс ниже. Этот файл нужно дополнить структурой и командами после
скаффолдинга.

## Стек
Astro 6, TypeScript strict, Tailwind 4. Статическая сборка.
Никаких новых зависимостей без явного согласования.

## Жёсткие ограничения
- Бюджет JS: <= 50 КБ на страницу
- Lighthouse: Perf/A11y/BP >= 95, SEO = 100
- Только токены из tailwind.config. Произвольные значения
  (text-[13px], #a3a3a3) запрещены
- Семантический HTML. Каждая интерактивная сущность доступна
  с клавиатуры
- Все анимации отключаются при prefers-reduced-motion
- Изображения только через <Image /> из astro:assets, avif/webp

## Процесс
- Одна секция лендинга = один коммит
- Перед коммитом: npm run build && npm run lint && npm run test:a11y
- После каждой секции сделать скриншоты на 360/768/1280 и показать
